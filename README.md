# AshkanSamimi.github.io
Personal website of Ashkan Samimi: https://ashkansamimi.github.io

Plain HTML/CSS/JS, no build step. `index.html` holds the whole home page (styles and scripts inline).
`cv.html` shows `assets/AshkanSamimi_CV.pdf`. `research.html` redirects to `index.html#research`.

To update the CV, replace `assets/AshkanSamimi_CV.pdf` with a file of the same name.
